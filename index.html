UDISE Lookup API Specification
CORS Enabled

The SMDb platform provides a public, cross-origin compatible REST endpoint for third-party admission portals, scholarship verification systems, and state education applications. Any external website can fetch complete 30-field school metadata asynchronously using fetch() without needing authentication credentials.

Client Webpage Integration Snippet (GET & POST) 
// 1. GET: Fetch existing school info to pre-fill registration form
async function fetchSchoolByUDISE(udiseCode) {
  const res = await fetch(`https://your-domain.com/api/schools/udise/${encodeURIComponent(udiseCode)}`);
  if (!res.ok) return null; // Not found: show empty registration form
  return await res.json();
}

// 2. POST: Upsert (Update existing school or Add new school with latest timestamp)
async function syncSchoolToSMDb(udiseCode, formData) {
  const res = await fetch(`https://your-domain.com/api/schools/udise/${encodeURIComponent(udiseCode)}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(formData)
  });
  return await res.json(); // returns { success, action: "updated"|"created", timestamp, data }
}
